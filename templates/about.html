Face Recognition Attendance

This automated attendance system harnesses the power of advanced computer vision to securely recognize faces and log attendance in real-time. It is designed to be fast, highly accurate, and completely removes the need for manual data entry.

Powered by: Python | Flask | OpenCV | SQLite

✨ Key Project Features

  • Face Registration: Automatically captures and processes multiple sample images to create a highly accurate facial profile for every new student.
  • Real-Time Recognition: Utilizes OpenCV algorithms to instantly detect and verify faces via the webcam with high precision.
  • Automated Logging: Records the student's identity along with the exact date and timestamp directly into a secure SQLite database.
  • Data Export: Allows administrators to generate and download attendance reports in CSV format with a single click for easy record-keeping.
  • Secure Access: The entire dashboard and its functions are protected behind an admin authentication system to prevent unauthorized changes.
